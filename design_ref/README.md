# design_ref

Taruh di folder ini: PRD_Barakah_v2.md, SRS_Barakah.pdf, design.md.

Aturan dokumen:
1. PRD v2.0 adalah acuan utama. SRS hanya pendukung.
2. Jika PRD dan SRS berbeda, PRD yang berlaku (nama endpoint dan format kode kebutuhan).
3. Kode kebutuhan memakai tanda hubung, misalnya FR-AUTH-01 dan AC-AUTH-01.
4. Nama endpoint memakai tanda hubung, misalnya /ai/zakat-explain dan /iot/next-prayer.
5. Nama berkas Dart memakai snake_case, nama kelas memakai PascalCase.
